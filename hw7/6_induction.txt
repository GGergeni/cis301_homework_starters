Use mathematical induction to prove that if n is natural number, then:

    1*1! + 2*2! + ... + n*n! = (n+1)! - 1

base case (n = 1)
the left side is 1*1!=1
right side is (1+1)!-1=2-1=1 
these match so the claim holds

inductive hypothesis 
    Assume the claim holds for some k >= 1

inductive step 
    1*1! + 2*2! + ... + k*k! +(k+1)*(k+1)! = (k+2)! -1
    1*1! + ... + k*k! +(k+1)*(k+1)! =[1*1! + ... k*k!]+ (k+1)*(k+1)!

            =(k+1)!-1(k+1)(k+1)!
            = (k+1)!(1(k+1))-1
            = (k+2)(k+1)!-1
            =(k+2)!-1


conclusion
    the claim for n =1 and whenever it is true for k is true for k + 1
